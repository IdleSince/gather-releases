# Gather für Windows

Gather ist eine Spielebox für Partyspiele mit Freunden. Die Windows-App öffnet einen Raum für die Spiele, die keinen
Fernseher brauchen. Du spielst am PC selbst mit, Freunde kommen ohne App und ohne Konto im Browser über
`gathergames.de/join/CODE` dazu (dafür braucht der PC Internet). Mehr zu den Spielen auf
[gathergames.de](https://gathergames.de).

Dieses Repository enthält nur die Installer und Update-Dateien der Windows-Version. **Der Quellcode ist nicht
öffentlich**, deshalb gibt es hier keinen Code, keine Issues und keine Pull Requests.

## Download

Die neueste Version: [Gather_x64-setup.exe](https://github.com/IdleSince/gather-releases/releases/latest/download/Gather_x64-setup.exe)
(Windows 10 und 11, x64). Ältere Versionen stehen unter [Releases](https://github.com/IdleSince/gather-releases/releases).

## Beta, unsigniert

Die Installer hier sind eine **Beta** und **nicht mit einem Code-Signing-Zertifikat signiert**. Windows SmartScreen
warnt deshalb beim Start („Der Computer wurde durch Windows geschützt“). Wer trotzdem installieren möchte, wählt
„Weitere Informationen“ und dann „Trotzdem ausführen“. Eine Garantie, dass die Warnung später verschwindet, gibt es
nicht.

Die installierte App sucht selbst nach Updates und installiert sie nur nach einem Klick. Updates sind mit einem
eigenen Schlüssel signiert, die App nimmt nur Dateien an, deren Signatur passt.

# Gather for Windows (English)

Gather is a party game box. The Windows app opens a room for the games that need no TV: you play on the PC, friends
join in their browser via `gathergames.de/join/CODE`, no app and no account needed. More at [gathergames.de](https://gathergames.de).

This repository only holds the installers and update files of the Windows version. **The source code is not
public.** The installers are an **unsigned beta**: Windows SmartScreen will warn before the first start. Privacy
policy: [gathergames.de/datenschutz](https://gathergames.de/datenschutz/).
